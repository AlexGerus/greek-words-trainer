# Мои греческие слова

Тренажёр греческих слов из уроков: карточки с интервальным повторением, ловушки на формы, спряжения, словарь и упражнение «Рассказ».

Весь тренажёр — один файл `index.html` без зависимостей и сборки. Прогресс хранится в браузере (localStorage) и переносится между устройствами файлом через «Словарь» → «Перенести прогресс на другое устройство».
